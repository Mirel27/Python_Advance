# Advanced Python | Hands-on Learning & Practice

A personal repository documenting my journey in strengthening advanced Python programming skills, with an emphasis on writing **clean, efficient, reusable, and testable code**.

The repository contains practical implementations of advanced Python concepts, focusing on their applications in **data engineering, automation, and software development**.

## Topics Covered

| Topic | Concepts |
|---|---|
| Object-Oriented Programming | Classes, objects, constructors, encapsulation and methods |
| Inheritance | Single, multiple and multilevel inheritance, MRO |
| Polymorphism & Decorators | Method overriding, reusable decorators and function wrappers |
| Multithreading | Concurrent execution, threads and thread pools |
| Pydantic | Data validation, type enforcement and models |
| Asynchronous Programming | Async/await, asyncio, concurrent tasks and execution |
| APIs | HTTP requests, API integration and response handling |
| Pytest | Unit testing, fixtures, parametrization and mocking |
| OS & File Operations | File handling, directory operations and automation |

## Key Learning Objectives

- Apply object-oriented design principles to build modular Python applications.
- Understand concurrency and the differences between threading and asynchronous programming.
- Implement data validation using Python type hints and Pydantic.
- Build and interact with APIs.
- Develop reliable unit tests using pytest and mock external dependencies.
- Write maintainable Python code following good software engineering practices.

## Getting Started

**Clone the repository**

`git clone https://github.com/Mirel27/Python_Advance.git`

`cd Python_Advance`

**Create a virtual environment**

`python -m venv .venv`

On Windows:

`.venv\Scripts\activate`

**Install testing dependencies**

`python -m pip install pytest pytest-mock`

Install any additional packages required by the individual exercises.

**Run tests**

`python -m pytest -v`

## Learning Approach

This repository follows a practical, hands-on approach:

1. Understand the underlying concept.
2. Implement examples independently.
3. Experiment with different approaches and edge cases.
4. Write tests to validate expected behaviour.
5. Refactor implementations for readability and reusability.

## Application to Data Engineering

The concepts explored here provide a foundation for developing production-oriented data engineering solutions, including:

- Reusable data ingestion and transformation components.
- Asynchronous API integrations and concurrent processing.
- Schema validation and automated data quality checks.
- Unit testing and mocking of external services.
- Modular, maintainable Python-based data pipelines.
